# Shared font assets

These Latin font subsets are vendored for the shared `@nl/ui` font loader so builds and
browser requests do not depend on Google Fonts availability.

- IBM Plex Sans: [SIL Open Font License](https://scripts.sil.org/OFL), copyright IBM Corp.
- Lilita One: [SIL Open Font License](https://scripts.sil.org/OFL), copyright Juan Pablo del Peral.
- Press Start 2P: [SIL Open Font License](https://scripts.sil.org/OFL), copyright CodeMan38.
