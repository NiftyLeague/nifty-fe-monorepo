# M2 disposable framework prototypes

These applications are isolated benchmark fixtures. They are not members of the root Bun workspace,
are not deployed, and do not share production routes. Each candidate implements the same public,
authenticated, data-heavy, interaction-heavy, streaming, and error-boundary surfaces with synthetic
data and no credentials.

Install and run a prototype from its own directory. The M2 benchmark manifest pins the commands and
measurement profile used for the committed evidence.
